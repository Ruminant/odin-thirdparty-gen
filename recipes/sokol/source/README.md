# Vendored Sokol sources

These C translation units and headers came from `Ruminant/sokol-odin-imgui` at commit
`701419c`, whose generated Odin bindings track upstream `floooh/sokol`.

They are build inputs owned by this repository. When updating Sokol, update these files
and the generated packages under `odin/sokol` together, then verify all native and
`web-wasm32` targets.
